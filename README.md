# Fluência — Sistema Inteligente de Nivelamento de Inglês com IA

## Breve Descrição
Aplicação full stack (.NET e React) para diagnóstico de proficiência em língua inglesa alinhado ao quadro CEFR (A1 a C2), com eliminação de chutes via opção **"Não sei responder"** e geração automática de cronogramas de estudo semanais via IA Generativa (GitHub Models).

## Motivação
Superar os diagnósticos enviesados por chutes aleatórios em testes convencionais e automatizar a prescrição pedagógica individualizada que hoje demanda tempo excessivo dos professores de idiomas.

## Tecnologias Utilizadas
- **Backend:** C#, .NET Web API, Entity Framework Core, Dapper e SQL Server (com Stored Procedures, Views e Functions).
- **IA Generativa:** GitHub Models API (GPT-4.1) via PAT.
- **Frontend:** React, TypeScript, Vite, Tailwind CSS.
- **Versionamento:** Git e GitHub.
